# OpenMTP development

The current fork's build, toolchain, isolation and offline test instructions are maintained in **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**.

Start with the [English README](README.md) or [README em português brasileiro](README.pt-BR.md). See [known limitations](docs/KNOWN_LIMITATIONS.md) and [publication readiness](docs/PUBLICATION_PLAN.md) before connecting devices or preparing a release.

The earlier upstream instructions mixed development with global tool installation, signing and publication and listed framework versions inconsistent with this checkout. They have been replaced with the shared guide. This change does not upgrade dependencies or authorize native rebuilding, packaging or publishing. Original upstream development guidance remains in the repository's existing Git history and [upstream project](https://github.com/ganeshrvel/openmtp).
