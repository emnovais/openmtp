## Measurements are observations, not promises

Historical bounded Legacy testing of a 916-file directory observed 24–36 mounted Grid tiles. One workload also observed a 370 ms worst frame gap while switching List and checking device access; List remains unvirtualized. Thumbnail `GeneralError (0x2002)` occurred for several selected objects. Successful later objects did not prove the cause of earlier failures or general USB health.

The checked-in [development baseline](development-baseline.md) is historical and includes both initial failures and subsequent startup corrections. It is not the current feature inventory. Raw later physical logs/screenshots contain device filenames and local context and remain private; this document summarizes their bounded results without publishing those listings.
